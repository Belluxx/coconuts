# Fonts

These fonts are bundled so the island works offline: [DM Sans](https://fonts.google.com/specimen/DM+Sans), [Manrope](https://fonts.google.com/specimen/Manrope), and [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif). They're the original TrueType files from Google Fonts.

Each family is under the SIL Open Font License. The license files are in this folder.
